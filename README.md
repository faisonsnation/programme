# Le programme de Faisons nation

Un candidat sans visage, un programme à découvert. Ni parti, ni réseau : un programme écrit en public, pour l'élection présidentielle de 2027.

Le site [faisonsnation.com](https://www.faisonsnation.com/programme/) affiche la dernière version de chaque fiche. Ce dépôt les garde toutes.

## Fiches publiées

Aucune fiche n'est encore publiée.

## Lire et comparer les versions

- Chaque fiche a son fichier, toujours le même. Une nouvelle version remplace son texte, et l'historique garde les précédentes.
- Chaque version publiée porte une étiquette, par exemple `apprendre-v1`. La liste est dans l'onglet *Tags*.
- Les fiches sont écrites à raison d'une phrase par ligne. Comparer deux versions montre exactement les phrases qui ont changé.

## Réagir, proposer, corriger

- Pour une idée, une objection ou une erreur, ouvrez une *issue* en choisissant le modèle qui convient. Vous pouvez aussi écrire à parlons@faisonsnation.com.
- Tout ce qui est écrit ici est public, de même que le nom de votre compte GitHub.
- Chaque message est lu. Une proposition retenue est reprise dans le travail sur la fiche et apparaît dans une version suivante.
- Les fichiers sont tirés des fiches validées et ne sont jamais modifiés directement : les demandes de fusion (*pull requests*) ne sont pas acceptées.
